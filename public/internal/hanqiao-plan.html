00 · Executive summary

执行摘要One page

协会与平台的合作不是「做一个技术项目」，而是把 AI 嵌进协会的课程、活动与国际中文项目。第一步是把最难、最不可复制的底层能力做对，而不是先做一个功能很多的平台。

项目一句话

以老师为根，以非洲为试金石，以弱网和离线为默认，把合规埋进地基里。汉桥是独立立项的项目，其对外入口 learn.gacee.org 由协会网站项目提供。

目标

9 月完成技术验证与合规框架；10 月中让一个真实的非洲班级在弱网条件下用起来；11 月底扩大试点。

灯塔场景

非洲，首选尼日利亚：协会已在 Great Heights School 与 New Horizon School 开展线上中文培训，是最现成的试点校。

合作模式

协会 + 当地教育部门 / 学校 + 技术平台。协会管内容、师资、国际资源与项目设计；平台管系统与 AI；当地学校负责真实落地。

八条原则

老师主导、无幻觉、普惠优先、弱网离线默认、母语脚手架、合规入地基、先轻后重、对齐标准与当地体系。

一个必须先说清楚的判断

备忘设定的「9–10 月完成 MVP」只有在把 MVP 定义为「录播 + 现成会议工具直播 + 网页版离线练习 + 一个伴学智能体」时才能守住。原生离线安卓 App 需要 10–12 周成熟期，建议排到 11 月中开始、2027 年 1 月发布测试版；10 月的试点班用可安装的网页应用（PWA）承接离线练习。这不是缩水，而是把「弱网离线」原则先在网页端兑现，再迁到原生端。

成功标准（11/27 试点复盘时验收）

  • 一个真实班级（20–40 名学员）在尼日利亚完成 6 周学习，出勤率与作业提交率有记录。
  • 老师每周实际投入课时下降，而学员练习量上升，两者都有日志数据。
  • 智能体答疑的抽样准确率与「拿不准转人工」的比例被度量，没有一起未被发现的错误判定。
  • 断网条件下学员仍能完成练习并在联网后同步，没有数据丢失。
  • 学校数据隔离、家长同意、数据出境三项合规要求有书面证据。

合作形态的两个选项

协会是非营利机构，不设合资实体、不持有平台股权、不以营利为目的分配收益；合作只在「委托开发 + 授权」与「联合运营 + 收入分成」两种形态之间选择，分成所得只用于协会章程范围内的教育与公益支出。

选项形态优点代价建议
1委托开发 + 软件授权：协会付费购买定制与授权，平台按年收授权与运维费权责清晰，协会拥有对系统的长期使用权协会前期现金压力大；平台缺乏共担动力推荐 1 + 2 混合：平台以极低授权费提供底座与运维，收入分成覆盖长期投入；协会承担内容与运营成本。试点期免授权费，以 MOU 约定；正式期签主协议。
2联合运营 + 收入分成：平台投入技术，双方按付费课程、企业委托班收入分成双方利益一致，前期投入低需要清楚的收入口径与结算机制；公益属性课程无收入

商业模式（与协会公益属性并存）

  • 机构席位：学校、华校、培训中心按学员席位购买，自带免费基础版，完整版按席位升级。这是平台已有的席位制，价格待定，不在本方案臆造。
  • 企业委托班：中资出海企业为本地员工开班，按班结算，出结业证书与学习报告。
  • 协会自有收入：活动报名费、研学费、作文大赛报名费、会员费，走协会自己的收款账户。
  • 公益资助：EduLink-Africa 与公益讲座由基金会与捐赠支持，普惠版免费给普通学校。

技术架构与技术路线JE Engine, the Agent Harness, and TIDAR KAG

本章把《JE 汉桥可行性与架构方案》的技术核心并入本方案，并按平台已经上线的真实能力更新：汉桥不是从零建一个平台，而是把 JurisEdu 已验证的 JE 引擎、可自助编排的 Agent 底座（Agent Harness）与低幻觉的 TIDAR KAG 作为核心大脑，在其上叠加跨境弱网媒体、离线优先客户端与中文教研三层新能力。

以 JurisEdu 沉淀的云中立企业级 Agent Harness 为核心大脑（复用后端、课程知识图谱、JE 引擎 / JE Agent、TIDAR KAG；基线部署新加坡，可跨云迁移），其上叠加三层新能力：跨境弱网媒体层（直播 / 录播）、离线优先客户端（App / Web）、每用户个性化记忆的 Agent 编排层。中国老师侧与非洲学员侧各接一条针对性优化的网络路径。

编排、模型、数据、评估、治理做成横向底座，汉桥与后续垂直项目共用一套运行时；新 Agent 只写「定义 + 工具 + 评估集」，不再重建基础设施。

四、TIDAR KAG：低幻觉的来源

TIDAR KAG 是平台自研的「知识图谱可溯源生成」，不是通用向量 RAG。它先在法律域验证，再移植到教育课程图谱并已上线。三个支柱决定了它为什么不编：

时序 Temporal

任何判断都基于某一时间点之前的真实作答快照（as-of），两个时间点之间可做逐知识点差分：进步、回落、新评估、无变化，全部如实呈现。

可溯源 Provenance

每个结论挂真实证据：作答记录、错题干、课程图谱中的先修 / 相关邻域；回答带出处，没有出处就不答。

可校准 Calibrated

掌握等级不用点估计，而用 Wilson 置信区间的下界判定：少于 3 题一律「证据不足」弃权，0 题为「尚未评估」；小样本的幸运连对绝不会被判成「已掌握」。

低幻觉机制规则汉桥中的落点
知识边界答疑只在课程图谱与教材范围内检索生成；图谱按「体系 → 学段 → 学科 → 领域 → 主题 → 知识点」组织，只写权威课标明列的结构新建「国际中文 HSK 3.0（三等九级）/ YCT」体系子树，每个词汇、语法点、场景挂等级与来源
弃权门置信不足或题型主观即弃权，交人处理弃权直接进入老师复核队列，试点周报统计转人工率
记忆非事实记忆只做检索证据与个性化风格，事实以图谱与实时计算的掌握度为准（compute-on-read）避免把过时结论当事实；学员换班、重学都能自动纠正
双 Agent 一致批改由评分与复核两个 Agent 独立判断，不一致取复核、存疑降级为未知，只有明确对错才写入图谱拍照作业与客观题评测沿用；口语评分分歧项转老师
写权分离Agent 只能提议，不能执行写动作；人批准后由系统执行，并留哈希链安排练习、调整进度、发证书均走审批
评估集每次发布跑课程内评估集：有出处率、错误率、转人工率不退步阶段 0 建 50 题，MVP 扩到 200 题

B 商用 RTC SDK需自定义课堂 / 白板 / 深度嵌入时，用具全球实时网络的 SDK（阿里云 RTC / Agora / 腾讯 RTC / ZEGO）体验可控、可深度集成记忆与评测；按分钟计费
C 自建 SFUWebRTC SFU（LiveKit / mediasoup / Janus）或低延迟 RTMP + 自建 TURN + 跨境加速边际成本低但运维重，规模化后再评估

三级降级与录制兜底

  • 一级：全互动直播（音视频 + 白板 + 实时问答）
  • 二级：关摄像头，保音频 + 板书 / 幻灯 + 字幕 + 文字互动
  • 三级：网络不可用转「课后 15 分钟内可回看的录播 + Agent 陪练补齐」
  • 每堂直播默认云端录制转 VOD，掉线学员无缝转看录播

弱网工程清单

  • 自适应码率 + Simulcast / SVC，分辨率帧率自动降级，优先保音频与白板
  • Opus + DTX + FEC / NACK / PLC 抗丢包；自适应抖动缓冲
  • TURN 中继兜底 NAT 穿透失败
  • 音频优先模式：只留语音 + 板书 + 字幕

录播与内容分发

  • 老师录课或直播录制 → 源站对象存储；老师音色 TTS 旁白、自动字幕（中 / 英 / 法）
  • FFmpeg 多码率 HLS / DASH（240p 至 720p + 纯音频档），切片加密
  • 源站 → 多 CDN，非洲边缘就近取流，断点续传
  • App 按内容包整节 / 整单元下载，加密存本地，退课可回收，可限 Wi-Fi 下载

离线优先客户端

  • 本地可用：已下载录播、随堂练、SRS 复习、笔顺、客观题作答与判分、录音留存
  • 本地库（SQLite / IndexedDB），内容包版本化；增量同步、出站队列、失败重试、断点续传
  • 冲突：学习进度「服务器权威 + 事件合并」，笔记 last-write-wins
  • 分级清理、省流、共享设备多账号切换、本地加密
